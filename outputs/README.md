# Fieldwise AI output images

This folder contains SVG figures for the README and research paper.

| Image | What it shows | Source boundary |
|---|---|---|
| [Catalogue by focus](images/catalogue_by_focus.svg) | 55 core records distributed as 11 records per assignment focus area | Catalogue structure only; not proof of full-text verification |
| [Catalogue by year](images/catalogue_by_year.svg) | Year counts for the 2021–2026 core records | Catalogue metadata |
| [Wheat-yield comparison](images/wheat_yield_same_study.svg) | R² and RMSE for two Random Forest configurations reported by Li et al. (2022) | One study; not a universal model ranking |
| [Selected vision metrics](images/selected_study_metrics.svg) | Tomato, coffee, and cotton study results shown in separate task panels | Accuracy, mAP, mIoU, precision, and recall are not interchangeable |
| [Dataset inventory](images/dataset_inventory_and_status.svg) | Named source datasets and whether raw data are bundled | Raw source datasets are generally not included |
| [Website architecture](images/project_architecture.svg) | React/Vite research site components and deployment flow | Describes the website, not an ML training pipeline |
| [Smart-agriculture pipeline](images/smart_agriculture_pipeline.svg) | Conceptual pipeline synthesised from the literature review | Conceptual diagram, not a deployed farm-control system |

The charts are explanatory research outputs. Fieldwise AI does not claim to train a new ML model on these datasets. The irrigation time series in the website is explicitly synthetic demo data.

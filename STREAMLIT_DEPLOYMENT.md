# Streamlit Community Cloud deployment

- Repository: `Vishnu1333/Role-of-AI-in-Smart-Agriculture-Solutions`
- Branch: `main`
- Main file path: `streamlit_app.py`

Sign in at [Streamlit Community Cloud](https://share.streamlit.io/), select **Create app**, choose the repository, `main` branch and `streamlit_app.py` entry point, then deploy. Commits on the configured branch can trigger redeployment. See the [official deployment guide](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy).

The Streamlit dashboard is a companion to the React/Vite website. It displays selected published results, not the accuracy of a newly trained Fieldwise AI model.
